Você sabe qual é o caminho que um site percorre na internet?

O caminho que um site percorre na internet ate chegar em nossas maquinas é dividido em etapas

1) Registro de Domínio

O anfitrião do site compra um endereço para seu site,servindo como um endereço oficial para as pessoas encontrarem o seu site.

Durante a compra é necessário checar as disponibilidade do nome do site desejado

No Brasil, isso é feito em órgãos oficiais ou revendedores autorizados (como o Registro.br).

Esse processo garante que o nome seja seu, evitando que outra pessoa use o mesmo endereço

2) Configuração do DNS

O nome do site e mudado em uma sequencia de números

Essa sequencia de números se chama de IP

Nesta etapa você tera que acessar o painel onde registrou seu domínio e configurar os endereços da DNS fornecidos pelo seu servidor

3) Contratação de Hospedagem

o anfitrião aluga um espaço e um computador potente, que fica conectado 24 horas por dia

Isso e conhecido como servidor

E nesse servidor que vão morar todos os É nesse servidor que vão morar todos os arquivos, imagens, códigos e bancos de dados do seu site

4) O Desenvolvimento e Envio dos Arquivos

Nessa etapa você cria o design e programa o site usando linguagens como HTML, CSS, JavaScript ou sistemas prontos de gerenciamento de conteúdo

Os arquivos prontos são enviados para dentro de sua hospedagem(servidor), ficando armazenados

5) Acesso e exibição no navegador

nessa etapa quando o usuário digitar seu endereço no navegador, o sistema vai consultar os servidores DNS para traduzir o nome legível em um endereço IP numérico

O navegador vai localizar o servidor correto,baixado os arquivos e renderizando a pagina na tela do usuário

Após todas essas etapas o site finalmente esta rodando e acessível no AR!
